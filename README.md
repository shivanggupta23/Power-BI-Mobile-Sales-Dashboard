# 📊 Mobile Sales Analytics Dashboard - Power BI

## Overview

This project is a comprehensive Business Intelligence dashboard developed using Power BI to analyze mobile sales performance across different cities, brands, payment methods, and time periods.

The solution provides interactive reporting and advanced analytical capabilities through DAX measures, data modeling, and time intelligence functions.

---

## Dashboard Pages

### 1. Executive Dashboard

Provides a high-level overview of business performance.

Features:

* Total Sales KPI
* Total Quantity Sold KPI
* Total Transactions KPI
* Average Price KPI
* City-wise Sales Analysis
* Monthly Quantity Trend
* Customer Rating Analysis
* Payment Method Distribution
* Mobile Model Performance
* Daily Sales Trend

---

### 2. Month-To-Date (MTD) Report

Tracks current period performance using DAX Time Intelligence.

Features:

* MTD Sales Analysis
* Daily Sales Trend
* Quarter, Month and Day Drilldown
* Dynamic Filtering
* KPI Monitoring

DAX Functions Used:

* TOTALMTD()
* CALCULATE()
* FILTER()

---

### 3. Same Period Last Year (SPLY) Analysis

Compares current performance against the corresponding period from the previous year.

Features:

* Year-over-Year Comparison
* Quarterly Sales Comparison
* Monthly Sales Comparison
* Variance Analysis
* Historical Performance Insights

DAX Functions Used:

* SAMEPERIODLASTYEAR()
* CALCULATE()
* DATEADD()
